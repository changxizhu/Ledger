数据所有权与系统边界

Ledger 不取代原始系统；它只负责收集、解释、评分和受控回写。

内容唯一所有者Ledger 行为
每周任务Linear Cycle + Issues读取完成情况；确认后生成下一周期。
工作主题Linear Projects关联证据并总结项目进度。
长期目标Linear Initiatives / Projects每月评估方向、风险和下阶段里程碑。
真实时间Google Calendar读取专注时间；仅写入批准后的时间块。
笔记产出MyNotes Git history只读取配置允许的路径和 diff。
代码产出Local Git history按身份别名汇总提交和变更证据。
模型互动Local hooks / exports原始内容仅保存在私有目录。
工作指数Ledger scripts从人工确认的标准化输入确定性计算。
公开 DashboardSanitized aggregates不能接触路径、提示词、任务标题或笔记正文。

核心隐私规则

原始证据止于 .ledger/。MCP 凭据止于连接器授权层。Subagents 只读。公开导出必须是独立、显式且经过验证的动作。
